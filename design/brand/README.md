# Originales de marca

Versiones en alta resolución de los logos y la foto. **No se publican** (no están en `public/`).

- La web usa las versiones optimizadas de `public/brand/` (generadas con sharp a partir de estos archivos).
- Las imágenes Open Graph de `public/og/` se generan con `npm run og` (ver `scripts/generate-og.mjs`).
